# NewCustomCuiLianPro v1.3.0 (Paper/Purpur 1.20.4+ 完整重制版)

## 本次 v1.3.0 重点修复与升级（对应全部 10 项改进）

1. **所有属性真实生效（内置原生属性与战斗引擎）**：
   - 无需安装 AttributePlus 或 SX-Attribute！内置 `NativeAttributeEngine` + `CombatAttributeListener` 直接驱动 Paper 1.20.4 原生属性与战斗结算：
     - **实时生效**：生命上限、物理防御（护甲）、盔甲韧性、移动速度、攻击速度、抗击退。
     - **战斗生效**：物理伤害（近战与弓/弩/三叉戟）、暴击几率、暴击伤害、吸血、闪避几率、伤害反弹。
   - 如服内已有其他属性插件，可在 `config.yml` 将 `NativeAttributeEngine: false` 关闭原生计算避免重复叠加。
2. **移除 Title 弹窗**：淬炼与宝石镶嵌均仅在聊天框显示提示，不再遮挡屏幕中央。
3. **10 大诗意宝石系列 × 5 阶（共 50 颗非方块图标宝石） + 宝石粘合剂 5 合 1**：
   - 青灵石（绿宝石-生命上限）、赤炎石（烈焰粉-物理伤害）、水夕石（海晶砂粒-闪避几率）、玄铁石（青金石-物理防御）、破军石（钻石-暴击几率）、星辉石（下界之星-攻击速度）、血珀石（红石粉-吸血）、风行石（羽毛-移动速度）、紫霄石（紫水晶碎片-暴击伤害）、沧澜石（回响碎片-盔甲韧性与反伤）。
   - 新增 **宝石粘合剂**（粘液球）：背包内左键拿起粘合剂，直接右键点击 1~4 阶宝石，自动消耗 5 颗同级宝石合成 1 颗下一阶宝石（最高 5 阶）。
4. **高星装备专属原生粒子特效（6 星起触发）**：
   - 只要**手持或穿戴**任意一件 ≥6 星装备即自动触发（无需 NashornJs/LLib）：
     - **6~8 星**：脚下旋转星辉魔法阵
     - **9~11 星**：脚下炽焰法阵 + 环绕双螺旋光带
     - **12~14 星**：背部 3D 扇动光翼 + 脚下法阵
     - **15~18 星**：紫金至尊双翼 + 脚下六芒星法阵 + 头顶星环光晕
5. **全道具附魔流光效果**：所有淬炼石、保护符、宝石（1~5 阶）、宝石粘合剂与拆卸符均自带附魔光效（隐藏附魔文字）。
6. **数值全面平衡**：
   - 武器淬炼每级严格 **+1 物理伤害**（1 星 +1 ~ 18 星 +18）；防具每件每级 **+0.5 物理防御**；宝石 1~5 阶温和线性成长（例如赤炎石 +1 ~ +5 伤害）。
7. **OP 全物品库 GUI (`/cuilian op`)**：
   - 54 格分页界面，底部按「淬炼石 / 保护符 / 镶嵌宝石 / 辅助道具」分类切换，左键拿 1 个、右键拿 16 个、Shift+左键拿 64 个。
8. **取消打孔与镶嵌界面，全部改为背包内一键右键直接完成（保留 `/cuilian moveLevel` 移星）**：
   - **镶嵌**：背包内左键拿起宝石 → 直接右键目标装备 → **一步直接镶嵌成功，无二次确认**。
   - **粘合**：背包内左键拿起宝石粘合剂 → 直接右键宝石 → 5 合 1 升阶。
   - **拆卸**：背包内左键拿起宝石拆卸符 → 直接右键装备即可取下（也保留 `/cuilian gem remove` 精准选择拆卸）。

## 升级提示（重要）

如果你之前运行过 v1.2.0，请**删除服务端 `plugins/NewCustomCuiLianPro/` 目录下的旧配置文件**（`config.yml`、`cuilian.yml`、`gem.yml`、`message.yml`），让插件自动重新生成 v1.3.0 的平衡配置与 5 阶宝石表！

```bash
mvn clean package
```
